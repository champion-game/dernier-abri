# BarriCard Clean UI Pack v1

Ce pack reprend la direction visuelle validée :
- métal noir / anthracite très sobre ;
- surfaces papier beige ;
- accent orange uniquement pour les actions importantes ;
- bordures or/laiton réservées aux cartes et objets importants ;
- cartes plus détaillées que l'interface pour renforcer l'effet "objet de collection".

## Structure
- `00_References` : concepts de référence et carte d'origine.
- `01_Screens` : écrans complets de référence.
- `02_Panels` : panneaux, slots deck/défausse et HUD.
- `03_Buttons` : états normal / hover / pressed / disabled.
- `04_Cards` : dos de carte et cadres normal/tank/heal.
- `05_Icons` : ressources et icônes d'interface.
- `06_Board` : cases et décors du plateau.
- `07_Tabs` : onglets et marque-pages.
- `08_Effects` : splatters, trait d'encre, sélections.
- `10_HTML_Demo` : maquette HTML/CSS sans dépendance externe.

## Intégration recommandée
Résolution cible PC : 1920×1080.
Grille : 9×9.
Utiliser l'orange uniquement pour l'action principale, la sélection ou le danger.
Utiliser les panneaux comme références pour du 9-slice lorsque les dimensions doivent varier.

Les exports transparents proviennent de la planche graphique générée pour ce pack.
Conserver `validated_clean_interface.png` comme référence principale pour la cohérence globale.
