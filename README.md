# Barricard (anciennement Dernier Abri)

Roguelite de cartes de survie zombie. Prototype jouable dans un navigateur.

## Jouer

En ligne : https://champion-game.github.io/dernier-abri/


Ouvre `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Tester l'équilibrage

Avec Node.js installé :

```
node tools/simulate.js
```
